# Spec Delta

## ADDED Requirements

### Requirement: Создание записи из голоса

Система ДОЛЖНА превращать сказанное в запись дневника тем же путём, что и фотографию:
сначала показать распознанный текст и посчитанные значения, и создать запись только после
подтверждения пользователем (SHALL).

#### Scenario: Сказал и подтвердил

- **WHEN** пользователь наговорил «два яйца и тост», проверил расшифровку и подтвердил карточку
- **THEN** в дневник добавляется одна запись с суммой по позициям

#### Scenario: Поправка расшифровки

- **GIVEN** распознавание услышало «борщ» как «борт»
- **WHEN** пользователь исправляет текст перед расчётом
- **THEN** расчёт идёт по исправленному тексту

#### Scenario: Отказ от записи

- **WHEN** пользователь закрывает карточку, не подтверждая
- **THEN** дневник не меняется
