## 2. Окно добавления

- [x] 2.1 Одна кнопка «Добавить еду» на экране дня вместо «Фото» и «Голос»
- [x] 2.2 Переписка: сообщения человека и ответы модели карточкой разбора
- [x] 2.3 Поле ввода с приложением снимка: снять или взять из галереи
- [x] 2.4 Уточнение меняет показанный разбор, переписка остаётся видимой
- [x] 2.5 Сохранение по подтверждению и подсказка, что без сохранения разговор пропадёт
- [x] 2.6 Ручной ввод чисел остаётся доступен из окна и для правки записей

Полная карточка с правкой позиций, порцией и сохранением — только у последнего разбора;
прежние разборы остаются в переписке одной строкой, чтобы одну и ту же еду нельзя было
сохранить дважды. Окно разговора заменяет прежний экран фотографии: способ ввода один.

## 3. Проверка

- [x] 3.1 Тесты разбора ответов и промпта
- [x] 3.2 Проверка вёрстки на узких экранах
- [ ] 3.3 Проверка на телефоне: словами, снимком и уточнением

Машиной проверено: окно открывается одной кнопкой, сообщение остаётся в переписке,
ошибка провайдера объясняется словами и предлагает повтор, ручной ввод чисел открывается,
на экране нет служебных слов, вёрстка на 320–430 пикселях без перелива.

Живой проверки ждут три случая, и все они требуют ключа — каждый запрос оплачивается:
разбор по словам, разбор по снимку со словами и уточнение, меняющее уже полученный разбор.
