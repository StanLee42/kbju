# Tasks

## План

### Файлы

- `openspec/changes/chat-survives-reload/`: предложение, решения, задачи, дельта спецификации
- `js/chat-session.js`: новый файл, запись и возврат разговора без разметки
- `js/ui/chat.js`: возврат разговора при открытии окна и запись при каждом изменении
- `js/ui/components/composer.js`: начальный текст поля и сообщение о набранном
- `js/ui/settings.js`: полный сброс чистит и разговор
- `tests/chat-session.test.mjs`: новый файл, проверки хранения

### Порядок

1. Дельта спецификации, проверка `openspec validate --all --strict`.
2. Файл хранения с тестами: он проверяется без браузера, поэтому пишется первым.
3. Подключение к окну добавления: возврат разговора и запись изменений.
4. Полный сброс в настройках.
5. Прогон всех проверок и разбор в браузере.

### Риски

- Вчерашний разбор всплывёт в новом дне, и запись уйдёт не туда. Рамкой служит дата в самой записи.
- Переполнение хранилища снимками. Откат к записи без снимков.
- Правка позиций в карточке потеряется при перезагрузке. Числа полосы сохраняются, карточка
  строится по ним.
- Возврат разговора задержит открытие окна. Запись читается из `sessionStorage` сразу,
  ожидания нет.

### Доказательство

- `node --test`: тесты хранения разговора.
- `openspec validate --all --strict`.
- `node tools/cdp-layout.mjs http://127.0.0.1:8767` и `node tools/cdp-check.mjs http://127.0.0.1:8767`.
- Прогон в браузере: отправить сообщение и набрать следующее, перезагрузить страницу,
  открыть окно добавления.
