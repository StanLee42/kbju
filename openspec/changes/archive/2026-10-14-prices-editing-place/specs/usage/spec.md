# Spec Delta

## MODIFIED Requirements

### Requirement: Стоимость считается по редактируемой таблице цен

Система ДОЛЖНА считать стоимость по таблице цен, которая хранит цену и дату, к которой она
относится, и помечать посчитанные суммы как оценку, а не как факт (SHALL). Таблица ДОЛЖНА
правиться на экране расхода, рядом с суммами, которые она объясняет (SHALL).

#### Scenario: Пиковые и непиковые часы

- **WHEN** запрос сделан в часы с другой ценой
- **THEN** стоимость считается по цене, действующей для этого времени

#### Scenario: Цены устарели

- **WHEN** пользователь смотрит расход
- **THEN** рядом с суммой указано, на какую дату действуют цены

#### Scenario: Правка таблицы

- **WHEN** человек меняет цену или дату таблицы на экране расхода
- **THEN** суммы считаются по новой таблице, а её дата видна там же

#### Scenario: Возврат значений по умолчанию

- **WHEN** человек возвращает значения по умолчанию
- **THEN** в таблице снова стоят цены, записанные в приложении, а суммы считаются по ним
