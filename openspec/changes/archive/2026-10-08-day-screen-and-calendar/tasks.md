# Tasks

## 1. Экран дня

- [x] 1.1 Тип дня одной плашкой с названием действующего типа
- [x] 1.2 Смена типа по нажатию на плашку: выбор появляется рядом и закрывается после выбора
- [x] 1.3 Строка нормы больше не повторяет название типа — только числа
- [x] 1.4 Отдельной кнопки добавления на экране дня нет
- [x] 1.5 Кнопка возврата к сегодняшнему дню, когда открыт другой день

## 2. Календарь

- [x] 2.1 Сетка месяца: недели с понедельника, дни соседних месяцев видны бледнее
- [x] 2.2 Листание месяцев, возврат к текущему месяцу
- [x] 2.3 Отметка съеденного за день; день без записей — только число
- [x] 2.4 Нажатие дня открывает его экраном дня, с записями и правкой
- [x] 2.5 Тесты расчёта сетки: начало месяца, конец месяца, високосный февраль, суммы по дням
