# Proposal

## Why

Пока первый этап описывался спецификациями, обнаружилось расхождение кода с задуманным
поведением: ручное переключение типа дня на экране дня всегда записывало исключение на дату,
даже когда выбранный тип совпадает с назначенным расписанием. В результате в настройках
накапливались записи-исключения, которые ничего не меняли, а подпись под датой сообщала,
что тип задан вручную, хотя фактически действовало расписание.

## What Changes

Выбор типа дня, совпадающего с расписанием, убирает исключение для этой даты вместо того,
чтобы создавать новое. Спецификация возможности `today-view` уточняется: у выбора появляется
явное требование не оставлять лишних исключений.

## Capabilities

### New Capabilities

Нет.

### Modified Capabilities

- `today-view`: требование «Выбор типа дня на текущую дату» уточняется — ручной выбор хранится
  исключением на дату, но выбор типа, который расписание уже назначает, исключения не создаёт

## Impact

Правка в `js/norm.js` (появилась функция «тип дня строго по расписанию, без исключений»),
в `js/state.js` (переключение убирает ненужное исключение) и тест расчёта. Интерфейс
не меняется: кнопки те же, меняется только след в хранилище.
